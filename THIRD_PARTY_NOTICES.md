# Third-party dependencies / 第三方依赖

The project license covers the project-authored code, not third-party dependencies. `starter/package.json` and `starter/package-lock.json` identify the dependencies used by the runnable example. Installed packages retain their own license and notice files.

本项目许可适用于项目自身代码，不替代第三方依赖许可。起步工程的依赖及固定版本见 `starter/package.json` 与 `starter/package-lock.json`。安装的依赖保留各自许可与通知文件。

- **Remotion and its packages**: [official license and terms](https://www.remotion.dev/docs/license). A commercial agreement with this project's maintainer does not itself grant any separately required Remotion license.
- **React / React DOM**: see the LICENSE files in the installed packages.
- **Inter / JetBrains Mono**, distributed through `@fontsource/inter` and `@fontsource/jetbrains-mono`: see the font license files supplied in those packages. Font files are bundled locally for rendering; the font packages are installed through npm rather than vendored into this repository.
- **TypeScript, tsx, type definitions and transitive dependencies**: see their installed license and notice files.

获得本项目的商业授权，不等于同时获得第三方软件、字体、音乐或品牌所需的授权。起步示例不附带配乐；请使用自己有权使用的音频。
